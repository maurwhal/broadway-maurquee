# Broadway Maurquee

Plain HTML + CSS, hosted on GitHub Pages.

- `index.html` — the whole site (Home, About, Budget Guide, Sites & Apps, Code)
- `style.css` — colors and layout (change the colors at the top in `:root`)
- `images/` — screenshots used in the guide
