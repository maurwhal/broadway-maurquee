# Broadway Maurquee

Maur's guide to seeing Broadway on a budget: lotteries, rush, memberships, and the sites I actually use.

Plain HTML + CSS, hosted on GitHub Pages.

- `index.html` — the whole site (Home, About, Budget Guide, Sites & Apps, Code)
- `style.css` — colors and layout (change the colors at the top in `:root`)
- `images/` — screenshots used in the guide

## Notice on AI assistance

This is a personal learn-to-code project. AI-assisted tools were used to help refine code and to generate some of the HTML/CSS. All guide content (the tips, opinions, recommendations, and screenshots) was sourced and written by **maurwhal**.
